# 平台是模板归属，承运商映射挂在平台上

平台不是资料库平级区。模板绑定平台、文档类型和方向。承运商映射挂在平台上，该平台的回填模板共用，避免换一份回填表头就复制一套快递对照。

承运商映射绑定需求（来源）平台，含义是「承运商描述/名称 → 该平台回填快递单号时接受的承运商 ID」，是一份宽松的对照而不是精确的承运商主数据。`InternalName` 保存工厂发货文件里出现的承运商写法（申通快递、韵达），`ExternalCode` 保存来源平台接受的 ID（回写布局里的 `shipment.carrier_code`），`InternalCode` 是可选的内部键，可以为空。匹配时先规范化名称（去空白、大小写折叠、去掉 快递/速运/物流/速递 后缀），先精确后包含；多个候选给出不同 ID 视为歧义，回写单元格留空并记录日志，让运营补映射而不是让系统猜。

工厂发货回传只保留文件里的承运商名称，不在工厂平台侧解析承运商编码；翻译发生在生成渠道回写时，按来源平台的映射进行。映射可以从来源平台导出的承运商表按表头导入，以规范化名称在平台内 upsert。
