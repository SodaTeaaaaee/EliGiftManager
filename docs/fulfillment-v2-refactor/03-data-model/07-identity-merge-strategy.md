# 身份归并策略

> `CustomerProfile` 跨平台身份归并的触发条件、规则和影响范围。

## 触发方式

- **手动归并**：始终可用，操作者显式选择两个 Profile 合并/拆分
- **自动归并**：默认关闭，用户在设置开启。触发条件可选（邮箱/手机号等）。先进入"建议归并"状态，用户确认后执行

## 归并规则

1. 保留较早创建的 Profile 作为主体
2. 被合并方的 `CustomerIdentity` 和 `CustomerAddress` 迁移到主体下
3. 被合并方标记为已归并

## 对已有数据的影响

- **已有 WaveParticipantSnapshot**：不回溯修改，历史快照保持原样
- **未来波次**：归并后只产生一个快照，关联主体 Profile
- **活跃波次**：如两个 profile 都已参与，提示用户决定是否合并快照

## 可撤销性

归并/拆分操作作为 `HistoryNode`，可通过 undo 撤销。

## 首版范围

实现：手动归并/拆分、自动归并配置界面和框架、归并建议队列。

不实现：复杂模糊匹配、跨系统 OAuth 自动关联。
